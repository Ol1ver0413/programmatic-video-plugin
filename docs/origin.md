# 从一次像素 MV 实验开始

第一条验证作品使用 O’3300 的 45 秒选段。第一版的主要问题是场景和动作太少，人物只是跟着歌词在背景上移动。

第二版增加到 24 个镜头、8 组背景和三套造型。改进重点是可见的过程：开门上车、握住并拉开栏杆、戴上面具、运球起跳扣篮。音频与字幕时间轴保留，重新组织画面和动作。

这些经验进入了本插件：

- **先锁定时间轴。** 原曲时间与成片时间分开，裁切后统一减去起点。已选音频不因视觉迭代被重新剪切。
- **生成图只是资产。** 有角色图不代表有动画；还需要姿态、挂点、事件时刻、场景变化与结果。
- **准确文字单独绘制。** 实验中吊坠必须是四位 3300；把数字交给图像生成会出错，统一挂点又会在蹲跳时漂移，所以改为逐姿势定位后绘制。
- **透明背景需要检查。** 一张看似白底的图集可能带半透明底色，叠加后仍然遮住场景。
- **静帧与连续帧都要看。** 一张扣篮图看起来成立，连续播放时球却可能没跟着手走。
- **导出也需要验证。** 最终检查实际 MP4 的字幕与角色细节，确认时长、尺寸、音轨和完整解码；不只检查浏览器里的画面。

保留的是这些方法和可运行工具。具体歌词、艺人造型、24 镜头数量、八种背景与 45 秒时长不是插件默认要求。原歌曲和艺人照片没有进入插件包；运行样例使用原创图形和合成提示音。
